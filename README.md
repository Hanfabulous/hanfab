# IHSG Fundamental Screener

Screener saham IHSG berbasis fundamental (PER, PBV, ROE) yang dibangun dengan Python + Streamlit.  
Data bersumber dari Yahoo Finance.

✅ Fitur:
- Screening fundamental saham
- Filter: ROE, PER, PBV
- Urutkan berdasarkan ROE tertinggi

🚀 Cara menjalankan:
- Lokal: `streamlit run screener.py`
- Online: Deploy ke [Streamlit Cloud](https://streamlit.io/cloud)
